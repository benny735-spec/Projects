# 📊 Data Analytics Capstone Project

## 🔍 Project Overview
This capstone project focuses on analyzing business data to uncover meaningful insights and support data-driven decision making.  
The project simulates a real-world business scenario where raw data is cleaned, analyzed, and visualized using industry-standard tools.

---

## 🎯 Objectives
- Clean and prepare raw data for analysis
- Analyze key business metrics and trends
- Build interactive dashboards for decision makers
- Generate actionable insights and recommendations

---

## 🧰 Tools & Technologies Used
- **Power BI** – Data modeling, DAX, dashboards
- **SQL** – Data extraction, joins, aggregations
- **Python** – Data cleaning & analysis (Pandas, NumPy)
- **Excel** – Initial data exploration & validation

---

## 📂 Dataset Description
The dataset contains business transaction data including:
- Customer details
- Product information
- Sales & revenue data
- Order dates and quantities

*(Sample / anonymized data used for learning purposes)*

---

## 🔄 Project Workflow
1. **Data Collection**
   - Imported data from Excel / CSV files

2. **Data Cleaning**
   - Removed duplicates and null values
   - Corrected data types
   - Standardized column formats

3. **Data Analysis**
   - Sales trends analysis
   - Customer segmentation
   - Product performance evaluation

4. **Visualization**
   - KPI cards
   - Trend charts
   - Interactive slicers
   - Category & region analysis

---

## 📈 Key Insights
- Identified top-performing products and categories
- Observed monthly and yearly sales trends
- Detected low-performing regions and products
- Analyzed customer buying behavior
